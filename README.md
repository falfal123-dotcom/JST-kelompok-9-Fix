# Fashion-MNIST Image Classification using CNN

This project implements a Convolutional Neural Network (CNN) to classify clothing images from the Fashion-MNIST dataset into 10 different categories.

The model is developed using Python, TensorFlow, and Keras, covering the complete machine learning pipeline, from data preprocessing and model architecture design to training and evaluation.

## Project Highlights

- Dataset: Fashion-MNIST (70,000 grayscale images)
- Image resolution: 28 × 28 pixels
- Number of classes: 10
- Model: Deep Convolutional Neural Network (CNN)
- Framework: TensorFlow and Keras
- Test Accuracy: **93.09%**

## Key Processes

1. Dataset loading and preprocessing
2. Image normalization and reshaping
3. CNN architecture development
4. Model training and validation
5. Model evaluation using accuracy, confusion matrix, precision, recall, and F1-score

## Results

The final CNN model achieved **93.09% test accuracy**. The evaluation also includes a confusion matrix, classification report, misclassified image analysis, and prediction visualizations.

## Dataset

Fashion-MNIST consists of 70,000 grayscale images across 10 clothing categories, including T-shirt, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, and Ankle Boot.

## Tools & Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn

## Objective

The objective of this project is to explore CNN-based image classification and understand how deep learning models extract visual features to distinguish different clothing categories.
